# イベントパッケージエクスポート

`Analysis > Export Event Package...` は、Pyth-Ion で検出したナノポア通過イベント分析結果を一括で出力する機能です。

1つのエクスポート結果は、1つのフォルダとして保存されます。その中に、測定条件、イベント一覧、各イベントの波形、FFT、サブイベント情報が入ります。

## 使う前に

- 先に `Analyze` を実行して、イベント検出を済ませてください。
- 出力先には、新しいフォルダまたは空のフォルダを指定してください。既に中身があるフォルダには出力しません。
- イベント数が多い場合は進捗バーが表示されます。途中でキャンセルした場合でも、書き出し済みのイベントファイルは残ります。

## 用語

| 用語 | 説明 |
|---|---|
| イベント | Pyth-Ion が検出した電流変化の1区間です。 |
| サブイベント | 1つのイベントの中にある、より細かい状態変化です。サブイベント状態検出を有効にした場合に出力されます。 |
| sample index | 測定点の通し番号です。0から始まります。 |
| global | 測定データ全体で見た位置です。 |
| local | セグメント内で見た位置です。 |
| raw | 読み込んだ元の電流値です。 |
| filt | フィルタ後の電流値です。 |
| 相対時刻 | イベント開始、またはサブイベント開始を0秒とした時刻です。 |

## 出力ディレクトリ構造

出力先フォルダ名はユーザーが選択します。ダイアログでは、元ファイル名と時刻を含む名前が初期値として表示されます。

```text
<export_dir>/
  metadata.json
  segments.json

  events/
    index.json

    00001/
      meta.json
      trace.csv
      fft.csv

      subevents/
        index.json

        00001/
          meta.json
          trace.csv

        00002/
          meta.json
          trace.csv

    00002/
      meta.json
      trace.csv
      fft.csv

      subevents/
        index.json
```

イベントフォルダとサブイベントフォルダは `00001`, `00002`, ... のように5桁の番号で作られます。これはファイルを見やすく並べるためのフォルダ名です。Pyth-Ion上のイベント番号とは別に考えてください。

## 各ファイルの役割

| ファイル | 内容 |
|---|---|
| `metadata.json` | 書き出し全体に共通する情報です。元ファイル名、サンプリング周波数、フィルタ、ベースライン、検出しきい値が入ります。 |
| `segments.json` | 測定データを分割して扱っている場合の、各セグメントの開始・終了位置です。 |
| `events/index.json` | 書き出されたイベントの一覧です。各イベントフォルダ名を確認できます。 |
| `events/<event>/meta.json` | 1イベント分の要約情報です。開始位置、終了位置、滞留時間、電流ブロック量などが入ります。 |
| `events/<event>/trace.csv` | 1イベント分の電流波形です。raw電流とフィルタ後電流が入ります。 |
| `events/<event>/fft.csv` | 1イベント分のフィルタ後電流から計算したFFTです。サブイベントにはFFTは出力されません。 |
| `events/<event>/subevents/index.json` | そのイベントに含まれるサブイベントの一覧です。サブイベントがない場合は空です。 |
| `events/<event>/subevents/<subevent>/meta.json` | 1サブイベント分の要約情報です。 |
| `events/<event>/subevents/<subevent>/trace.csv` | 1サブイベント分の電流波形です。 |

## JSON ファイルについて

JSONファイルは、設定や要約情報を保存するためのテキストファイルです。

数値が計算できない場合は `null` になります。たとえば、フィルタ条件がない場合や値が未設定の場合です。

## `metadata.json`

このファイルには、エクスポート全体に共通する情報が入ります。

例:

```json
{
  "source_file_name": "sample.opt",
  "ADC_samplerate_Hz": 250000.0,
  "LPFilter_cutoff_Hz": 100000.0,
  "baseline_A": 1.23e-9,
  "baseline_std_A": 4.56e-12,
  "threshold_A": 3.0e-10
}
```

| 項目 | 内容 |
|---|---|
| `source_file_name` | 元データのファイル名です。 |
| `ADC_samplerate_Hz` | サンプリング周波数です。単位は Hz です。時刻の計算に使います。 |
| `LPFilter_cutoff_Hz` | 読み込み時に使ったローパスフィルタのカットオフ周波数です。単位は Hz です。 |
| `baseline_A` | 解析時のベースライン電流です。単位は A です。 |
| `baseline_std_A` | ベースライン電流の標準偏差です。単位は A です。 |
| `threshold_A` | イベント検出に使ったしきい値です。単位は A です。 |

## `segments.json`

このファイルには、測定データのセグメント範囲が入ります。通常の利用では頻繁に見る必要はありませんが、`seg` や `local_startpt` を正確に解釈したい場合に使います。

例:

```json
[
  {
    "seg": 0,
    "start": 0,
    "end": 250000
  }
]
```

| 項目 | 内容 |
|---|---|
| `seg` | セグメント番号です。0から始まります。 |
| `start` | このセグメントが測定データ全体の何点目から始まるかを示します。 |
| `end` | このセグメントが測定データ全体の何点目で終わるかを示します。 |

## `events/index.json`

このファイルには、書き出されたイベントの一覧が入ります。

例:

```json
[
  {
    "event_index": 0,
    "path": "00001"
  },
  {
    "event_index": 1,
    "path": "00002"
  }
]
```

| 項目 | 内容 |
|---|---|
| `event_index` | Pyth-Ion上のイベント番号です。0から始まります。 |
| `path` | そのイベントのフォルダ名です。例では `events/00001/` と `events/00002/` を指します。 |

## `events/<event>/meta.json`

このファイルには、1つのイベントの要約情報が入ります。イベントの長さ、位置、電流ブロック量だけを確認したい場合は、このファイルを見ます。

例:

```json
{
  "event_index": 0,
  "seg": 0,
  "local_startpt": 1200,
  "local_endpt": 1450,
  "global_startpt": 1200,
  "global_endpt": 1450,
  "t_start_s": 0.0048,
  "t_end_s": 0.0058,
  "dwell_us": 1000.0,
  "deli_A": 3.4e-10,
  "frac": 0.27
}
```

| 項目 | 内容 |
|---|---|
| `event_index` | Pyth-Ion上のイベント番号です。 |
| `seg` | このイベントが含まれるセグメント番号です。 |
| `local_startpt` | セグメント内でのイベント開始位置です。単位は測定点です。 |
| `local_endpt` | セグメント内でのイベント終了位置です。単位は測定点です。 |
| `global_startpt` | 測定データ全体でのイベント開始位置です。単位は測定点です。 |
| `global_endpt` | 測定データ全体でのイベント終了位置です。単位は測定点です。 |
| `t_start_s` | 測定開始から見たイベント開始時刻です。単位は秒です。 |
| `t_end_s` | 測定開始から見たイベント終了時刻です。単位は秒です。 |
| `dwell_us` | イベントの滞留時間です。単位は us です。 |
| `deli_A` | 電流ブロック量です。単位は A です。 |
| `frac` | 分数電流ブロックです。ベースラインに対するブロック量の比として扱います。 |

このファイルには、画面で直接確認する主要な値だけを入れています。平均値、標準偏差、歪度、尖度、FFT平均値などの追加統計量は出力していません。

## `events/<event>/trace.csv`

このファイルには、1つのイベント区間の電流波形が入ります。

例:

```text
sample_index,t_abs_s,t_event_s,raw_A,filt_A
1200,4.800000000000000170e-03,0.000000000000000000e+00,1.210000000000000002e-09,1.200000000000000004e-09
1201,4.804000000000000436e-03,3.999999999999999819e-06,1.180000000000000002e-09,1.170000000000000004e-09
```

| 列 | 内容 |
|---|---|
| `sample_index` | 測定データ全体での測定点番号です。 |
| `t_abs_s` | 測定開始からの時刻です。単位は秒です。 |
| `t_event_s` | イベント開始からの時刻です。イベントの最初の点が0秒になります。 |
| `raw_A` | 元の電流値です。単位は A です。 |
| `filt_A` | フィルタ後の電流値です。単位は A です。FFTはこの列から計算されます。 |

## `events/<event>/fft.csv`

このファイルには、1つのイベントのフィルタ後電流から計算したFFTが入ります。周波数ごとの実部、虚部、大きさ、位相を出力します。

サブイベントには `fft.csv` は作られません。

例:

```text
frequency_Hz,real_A,imag_A,magnitude_A,phase_rad
0.000000000000000000e+00,1.230000000000000031e-08,0.000000000000000000e+00,1.230000000000000031e-08,0.000000000000000000e+00
1.000000000000000000e+03,2.100000000000000060e-11,-3.999999999999999759e-12,2.137755832643195403e-11,-1.881928030096923072e-01
```

| 列 | 内容 |
|---|---|
| `frequency_Hz` | 周波数です。単位は Hz です。 |
| `real_A` | FFT値の実部です。 |
| `imag_A` | FFT値の虚部です。 |
| `magnitude_A` | FFT値の大きさです。 |
| `phase_rad` | FFT値の位相です。単位は rad です。 |

FFTは、`trace.csv` の `filt_A` に対して計算されます。ビン化や平均化はしていません。また、出力値はイベント長で正規化していません。長さの異なるイベント同士を比較する場合は、必要に応じて正規化してください。

## `events/<event>/subevents/index.json`

このファイルには、1つのイベント内にあるサブイベントの一覧が入ります。サブイベントがない場合は `[]` になります。

例:

```json
[
  {
    "state_id": 1234,
    "state_index": 0,
    "path": "00001"
  }
]
```

| 項目 | 内容 |
|---|---|
| `state_id` | Pyth-Ionがサブイベントを区別するための番号です。 |
| `state_index` | 親イベント内でのサブイベント番号です。0から始まります。 |
| `path` | そのサブイベントのフォルダ名です。例では `subevents/00001/` を指します。 |

## `events/<event>/subevents/<subevent>/meta.json`

このファイルには、1つのサブイベントの要約情報が入ります。

例:

```json
{
  "state_id": 1234,
  "state_index": 0,
  "seg": 0,
  "local_startpt": 1280,
  "local_endpt": 1340,
  "global_startpt": 1280,
  "global_endpt": 1340,
  "t_start_s": 0.00512,
  "t_end_s": 0.00536,
  "dwell_us": 240.0,
  "deli_A": 2.8e-10,
  "frac": 0.22
}
```

| 項目 | 内容 |
|---|---|
| `state_id` | Pyth-Ionがサブイベントを区別するための番号です。 |
| `state_index` | 親イベント内でのサブイベント番号です。 |
| `seg` | このサブイベントが含まれるセグメント番号です。 |
| `local_startpt` | セグメント内でのサブイベント開始位置です。単位は測定点です。 |
| `local_endpt` | セグメント内でのサブイベント終了位置です。単位は測定点です。 |
| `global_startpt` | 測定データ全体でのサブイベント開始位置です。単位は測定点です。 |
| `global_endpt` | 測定データ全体でのサブイベント終了位置です。単位は測定点です。 |
| `t_start_s` | 測定開始から見たサブイベント開始時刻です。単位は秒です。 |
| `t_end_s` | 測定開始から見たサブイベント終了時刻です。単位は秒です。 |
| `dwell_us` | サブイベントの滞留時間です。単位は us です。 |
| `deli_A` | サブイベントの電流ブロック量です。単位は A です。 |
| `frac` | サブイベントの分数電流ブロックです。 |

親イベントの番号は、このファイル内には書いていません。`events/00001/subevents/00001/` のように、フォルダの場所から親イベントが分かるためです。

## `events/<event>/subevents/<subevent>/trace.csv`

このファイルには、1つのサブイベント区間の電流波形が入ります。親イベント開始からの時刻と、サブイベント開始からの時刻の両方が入っています。

例:

```text
sample_index,t_abs_s,t_parent_event_s,t_subevent_s,raw_A,filt_A
1280,5.120000000000000107e-03,3.200000000000000083e-04,0.000000000000000000e+00,9.500000000000000551e-10,9.399999999999999795e-10
1281,5.124000000000000373e-03,3.239999999999999981e-04,3.999999999999999819e-06,9.600000000000000038e-10,9.499999999999999521e-10
```

| 列 | 内容 |
|---|---|
| `sample_index` | 測定データ全体での測定点番号です。 |
| `t_abs_s` | 測定開始からの時刻です。単位は秒です。 |
| `t_parent_event_s` | 親イベント開始からの時刻です。 |
| `t_subevent_s` | サブイベント開始からの時刻です。サブイベントの最初の点が0秒になります。 |
| `raw_A` | 元の電流値です。単位は A です。 |
| `filt_A` | フィルタ後の電流値です。単位は A です。 |
